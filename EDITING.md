# Editing this GitHub profile

The root README.md is the content displayed on the public musmanbhutta GitHub profile. The repository must be public and have the same name as the account: musmanbhutta/musmanbhutta.

Edit README.md to update the introduction, technologies, case studies or portfolio links. Keep claims specific to work you personally contributed. The three case-study areas describe selected contributions, not ownership of three entire applications.

## Visual assets

assets/banner-dark.svg and assets/banner-light.svg provide the banner variants. GitHub supports a picture element with prefers-color-scheme media queries. The visitor's browser color preference chooses a variant; GitHub controls the surrounding page theme.

assets/button-portfolio.svg and assets/button-documents.svg provide the two link graphics. The README includes descriptive alternative text. Ordinary text links remain at the bottom as a fallback when images are unavailable.

The SVG files are small and self-contained. They include no scripts, remote fonts, external images or tracking. The profile has no dependency on a stats-card service, account token, scheduled workflow or running Docker container. The repository stores only sanitized profile content, graphics and these editing instructions.

## GitHub limitations

A profile README customizes the introduction area. GitHub controls the surrounding navigation, layout, contribution graph and account theme. README formatting is GitHub Flavored Markdown with supported HTML; it is not a custom application with arbitrary CSS or JavaScript.

GitHub's native contribution graph remains the source of current activity. No contribution totals, skill percentages or proficiency rankings are maintained in this README.
